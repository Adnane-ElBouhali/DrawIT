# Quick Draw Game

This project is an implementation of a "Quick Draw" game using the Quick, Draw! dataset by Google. It features a neural network trained to recognize hand-drawn sketches, challenging users to draw specific objects while the AI attempts to identify them in real-time.

## Overview

The Quick Draw Game is an interactive application that:
- Prompts users to draw specific objects
- Uses a trained neural network to recognize the sketches
- Provides instant feedback to players on their drawings

The game leverages the extensive Quick, Draw! dataset created by Google, which contains millions of drawings across various categories.

## Features

- Real-time sketch recognition
- User-friendly drawing interface
- Diverse range of objects to draw
- Instant feedback on sketch recognition
- Score tracking and performance metrics
